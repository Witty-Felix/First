# 电机模块说明

## 🧭 整体架构

```
┌──────────────────────────────────────────────────────┐
│                    MCU (STM32F107)                    │
│                                                      │
│  TIM5_CH1 (PA0) ────── PWM脉冲信号 ──────┐          │
│  GPIOE12    ────── 方向电平 (正/反) ─────┤          │
│  GPIOB11    ────── 使能电平 (开/关) ─────┤          │
│                                           │          │
│  GPIOC13 ──┐                              │          │
│  GPIOC14 ──┤── 限位开关 (触发中断)        │          │
│             │                             ▼          │
│             │                     [电机驱动器]       │
│             │                           │            │
│             │                           ▼            │
│             │                       [步进电机]       │
└─────────────┴────────────────────────────────────────┘
```

---

## 一、硬件连接

| MCU引脚 | 接什么 | 控制什么 |
|---------|--------|---------|
| **PA0** (TIM5_CH1) | 电机驱动器脉冲输入 | 发PWM脉冲，控制电机速度和位置 |
| **PE12** | 电机驱动器方向输入 | 高=反转，低=正转 |
| **PB11** | 电机驱动器使能输入 | 低=使能(电机能动)，高=禁止 |
| **PC13** | 左限位开关 | 触发中断，通知MCU"撞到左边了" |
| **PC14** | 右限位开关 | 触发中断，通知MCU"撞到右边了" |

## 二、数据结构

相关文件：[Inc/bsp/motor.h](Inc/bsp/motor.h)

### 枚举定义

```c
// 方向枚举
typedef enum { FORWARD = 0, BACKWARD } Motor_Dir_e;

// 使能枚举
typedef enum { ENA = 0, DIS } Motor_En_e;
```

### 电机结构体

```c
typedef struct 
{
    Motor_Dir_e  Motor_Dir;      // 方向: FORWARD(0) 或 BACKWARD(1)
    Motor_En_e   Motor_En;       // 使能: ENA(0) 或 DIS(1)
    uint16_t     Speed;          // 速度: 1000~2000 (脉冲/秒)
    uint32_t     Pulse_Max;      // 目标脉冲数（默认6400 = 转一圈）
    uint32_t     Pulse_Count;    // 当前已发脉冲数
} Motor_t;
```

`Motor_t` 像一张"电机档案卡"，记录电机当前往哪转、转多快、要转多少步。全局变量 `Motor` 定义在 [Src/bsp/motor.c](Src/bsp/motor.c) 第6行。

## 三、API 函数

### 3.1 初始化

| 函数 | 做什么 | 谁调用 |
|------|--------|--------|
| `Motor_Dir_EN_Init()` | 初始化方向(PE12)和使能(PB11)引脚为推挽输出 | `MOTOR_Init()` 内部 |
| `TIM5_PWM_Init(arr, psc)` | 配置TIM5为PWM模式，PA0输出脉冲。只配置**不启动** | `MOTOR_Init()` 内部 |
| `MOTOR_Init(Motor_t *Motor)` | **总初始化**：检测限位开关确定初始方向→设置速度→调上面两个Init | `main()` |

### 3.2 基础控制

| 函数 | 做什么 | 参数 |
|------|--------|------|
| `MOTOR_Dir(val)` | 设置方向 | `FORWARD` 或 `BACKWARD` |
| `MOTOR_EN(val)` | 使能/禁止驱动器 | `ENA`(允许转) 或 `DIS`(禁止转) |
| `MOTOR_Speed(speed)` | 设置速度（改PWM频率） | 1000~2000 |
| `MOTOR_Pulse(val)` | 开启/关闭脉冲输出 | `ENABLE` 或 `DISABLE` |
| `PWM_SetARR(speed)` | 底层：改PWM周期（调频率=调速度） | speed值 |
| `PWM_SetCRR(speed)` | 底层：改占空比（保持50%） | speed值 |

### 3.3 运行控制

| 函数 | 做了什么 |
|------|----------|
| `MOTOR_Start(Motor_t *Motor)` | **启动**：按结构体里的方向&速度开始发脉冲 |
| `MOTOR_Stop()` | **停止**：关脉冲，置停止标志 |
| `MOTOR_Resume()` | **恢复**：重新开脉冲，清停止标志 |
| `MOTOR_Change_Dir(Motor_t *Motor)` | **换向**：正转↔反转 切换 |

## 四、PWM 脉冲产生原理

```
系统时钟 72MHz
     │
     ▼
预分频器 (PSC=10)  →  72MHz / 10 = 7.2MHz
     │
     ▼
自动重装 (ARR)     →  7.2MHz / ARR = 实际脉冲频率
     │                   
     ▼
比较值 (CCR)       →  CCR = ARR/2 → 占空比总是 50%
```

速度公式：`实际脉冲频率 = 7,200,000 ÷ (7200000/speed) = speed`（单位：脉冲/秒）

例如 `Speed = 1000`：每秒发 1000 个脉冲，走一圈(6400脉冲)需要 **6.4秒**。

## 五、限位开关联动逻辑

这是两个"触发源"配合一个"状态机"实现的。

### 触发源1：外部中断

相关文件：[Src/bsp/AppFunc.c](Src/bsp/AppFunc.c) 第90行

```
限位开关被碰撞 (PC13 或 PC14 从高→低)
        │
        ▼
CPU 触发 EXTI15_10_IRQHandler 中断
        │
        ▼
设置全局标志 Move_End = 1
然后退出中断（不做其它硬件操作）
```

**设计意图**：中断里只设标志位，不做实际控制，避免在中断里做复杂操作导致系统卡死。

### 触发源2：主循环状态机

相关文件：[Src/bsp/motor.c](Src/bsp/motor.c) 第181行

```
   ┌──────────┐    Move_End==1     ┌──────────┐
   │  IDLE1   │ ─────────────────→ │ DEBOUNCE │
   │ (空闲)   │                    │ (消抖)   │
   └──────────┘                    └────┬─────┘
        ▲                              │
        │                         10ms后还按着？
        │                              │
        │                         是 ▼ 否 ──→ 回到IDLE1
        │                     ┌──────────┐
        │                     │ STOPPED  │
        │                     │ (已处理) │
        │                     └────┬─────┘
        │                          │
        └──────────────────────────┘
            等 300ms 后再允许下一次
```

状态机做了中断没做的事：
1. **DEBOUNCE（消抖）**：等待 10ms 确认不是误触
2. **执行换向**：调用 `MOTOR_Change_Dir()` + `MOTOR_Start()` 让电机往反方向转
3. **STOPPED（冷却）**：等 300ms 后再恢复检测，防止反复触发

## 六、main() 中的电机控制流程

相关文件：[Src/main.c](Src/main.c)

```c
int main(void)
{
    // 1. 基础初始化
    NVIC_PriorityGroupConfig(NVIC_PriorityGroup_2);
    LED_Init();
    SysTick_Init();
    LimSwc_Init();             // 初始化限位开关+外部中断
    
    // 2. 电机初始化
    MOTOR_Init(&Motor);        // 探测当前限位状态 → 决定初始方向
                               // 设置速度=MIN_SPEED(1000)
                               // 目标脉冲数=PULSE_NUM(6400)
    
    // 3. 手动控制
    MOTOR_EN(ENA);             // 使能驱动器
    Motor.Speed = 200;         // 设置速度为 200 脉冲/秒
    MOTOR_Change_Dir(&Motor);  // 切换一次方向
    MOTOR_Start(&Motor);       // 启动电机！
    
    // 4. 分支
    if(0)   // ← if(0) = 永远不进
    {
        while (1)
        {
            MOTOR_Check_Status(&Motor);  // 不断检测限位 → 自动换向
        }
    }
    else
    {
        MOTOR_EN(DIS);         // 直接关使能，电机停转
    }
}
```

**当前实际行为**：电机启动后立即被 `MOTOR_EN(DIS)` 关掉了——电机转不起来。

**如果想自动来回跑**：把 `if(0)` 改成 `if(1)`，电机就会：
1. 启动往一个方向转
2. 碰到限位开关 → 中断设标志
3. 状态机检测到标志 → 消抖 10ms → 换向启动
4. 往反方向转 → 碰另一边的限位 → 再换向，如此往复

## 七、关键参数

| 宏 | 值 | 含义 |
|----|----|------|
| `MAX_SPEED` | 2000 | 最快 2000 脉冲/秒 |
| `MIN_SPEED` | 1000 | 最慢 1000 脉冲/秒 |
| `PULSE_NUM` | 6400 | 转一圈需要 6400 个脉冲 |
| `TIM5_ARR` | 7200 | PWM 自动重装初值 |
| `TIM5_PSC` | 10 | PWM 预分频值 |

